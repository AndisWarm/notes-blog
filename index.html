AndisWarm的知识库

AndisWarm 的个人知识库 · 当前聚焦后端面试八股文，基于小林 coding面试系列整理。每个专题采用「一句话回答 → 展开讲 → 比喻 → 面试怎么答」的结构，用大白话把底层原理讲透。

使用提示 Tips

通过主题和目录以打开文章：

  • Mac/PC 端：请在上方标签栏选择主题，在左侧目录选择文章
  • 移动端：请点击左上角图标选择主题和文章
  • 也可以使用顶部搜索关键词快速打开文章

  1. 先从 MySQL / Redis 入手，这两块是后端面试最高频考点；
  2. 再补 操作系统 与 计算机网络 的基础知识；
  3. 然后进入 消息队列 与 分布式 的中级内容；
  4. 最后用 系统设计 与 后端技术进阶之路 串联成完整的架构认知。
