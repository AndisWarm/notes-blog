# Redis 面试知识讲解

## 推荐阅读顺序

1. 先过 [01](01_数据类型与使用场景.md) 和 [07](07_缓存应用场景.md)，建立"Redis 能干什么"的整体感觉
2. 再学 [02](02_底层数据结构.md)，底层结构是面试最容易被深挖的地方（跳表、渐进式 rehash）
3. 然后 [03](03_线程模型.md) → [04](04_事务与持久化.md)，理解"为什么快"和"数据怎么不丢"
4. 接着 [09](09_缓存一致性、三大问题与秒杀.md)，缓存三大问题是几乎必问的业务题，三个概念一定要分清
5. 最后 [05](05_过期删除与内存淘汰.md)、[06](06_集群架构.md)、[08](08_分布式锁与大Key热Key.md) 收尾
