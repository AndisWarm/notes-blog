# 后端技术进阶之路（小林 coding 面试系列讲解）

面向编程小白的后端面试知识进阶讲解，基于小林 coding「后端技术进阶之路」总目录（[原文链接](https://www.xiaolincoding.com/interview/win.html)），按「由浅入深、循序渐进」的方式组织，从计算机基础原理到架构设计实战。

每个问题都采用「一句话回答 → 展开讲 → 比喻」的讲解结构，配合表格对比，帮助零基础读者建立系统认知。

## 推荐阅读顺序

1. 先学 [01_计算机基础](01_计算机基础.md)，打牢操作系统、网络原理
2. 再学 [02_数据库与存储](02_数据库与存储.md)，掌握各类数据存储方案
3. [03_设计模式与代码优化](03_设计模式与代码优化.md) 和 [04_消息队列](04_消息队列.md) 建立代码思想与异步通信认知
4. [05_系统设计与架构](05_系统设计与架构.md) → [06_高并发与性能优化](06_高并发与性能优化.md)，积累实战与优化经验
5. 最后 [07_分布式系统](07_分布式系统.md) → [08_微服务架构](08_微服务架构.md) → [09_云原生技术](09_云原生技术.md)，理解现代分布式架构
