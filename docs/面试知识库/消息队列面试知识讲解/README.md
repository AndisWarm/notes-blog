## 推荐阅读顺序

1. 先过一遍 [01](01_消息队列是什么与为什么.md) 和 [02](02_消息队列选型.md)，建立 MQ 的整体认知（为什么用、怎么选）
2. 再学 [03](03_消息可靠性.md) → [04](04_幂等与消息积压.md) → [05](05_事务消息与数据一致性.md)，这三个是面试必考的深水区（可靠性、幂等、积压、事务消息）
3. 然后按 [07](07_RocketMQ详解.md) → [08](08_Kafka详解.md) → [09](09_RabbitMQ详解.md) 逐个击破三大中间件
4. [06](06_设计模式与架构设计.md) 的系统设计题可放最后，属于拔高题

## 本章重点提示（小林原文强调）

- **消息可靠性**：生产者、Broker、消费者三环节各自怎么保证不丢消息，必考题
- **重复消费和幂等**：为什么重复、怎么设计幂等方案，与业务结合最紧
- **消息积压**：如何快速处理，RocketMQ 队列数和消费者数的关系是很多人的盲区
- **Kafka 和 RocketMQ 的区别**：存储模型、协调机制、适用场景，高频对比题
- **事务消息**：半消息机制怎么工作，答好了很加分
