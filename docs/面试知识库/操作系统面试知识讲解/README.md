## 推荐阅读顺序

1. **入门组**（建立整体框架）：[01](01_用户态与内核态.md) → [08](08_中断.md)。先理解"操作系统运行在哪、事件怎么响应"
2. **核心组**（面试主战场，必读）：[02](02_进程与线程.md) → [03](03_进程间通信.md) → [04](04_进程调度算法.md)。进程线程是出现频率最高的考点
3. **深水组**（拉开差距）：[05](05_锁与死锁.md)（死锁四条件 + 银行家算法必考）→ [06](06_内存管理基础.md) → [07](07_内存管理进阶.md)（写时复制、malloc、页面置换）
4. **加分组**（理解高性能服务器）：[09](09_网络IO模型.md)。select/poll/epoll 和零拷贝是 Redis/Nginx/Netty 的底层原理
