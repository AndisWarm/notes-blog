## 这套教程讲什么

你每天打开浏览器访问 HTTPS 网站，地址栏出现小锁图标，背后就是 **TLS 协议**在默默工作。TLS 要做的事情可以概括成三件事：

1. **确认对方是谁**（身份认证）——防止连到假网站；
2. **商量出一把只有双方知道的钥匙**（密钥协商）——防止内容被偷看；
3. **保证内容没被改过**（完整性校验）——防止内容被篡改。

而 **TLS 握手（Handshake）** 就是完成这三件事的"见面仪式"，整套协议里最精密、最复杂的部分。本教程会把握手从第一步到最后一步，掰开揉碎讲清楚。

## 阅读方法

- **每章结构**：先讲"它是什么、解决什么问题"，再拆细节，最后给「一张图总结」和「复习题」。
- **遇到名词看不懂**：先跳过，术语会在后续章节反复出现，越看越熟。最后第 8 章还有一份术语对照表。
- **想快速抓住主线**：只读 [02 全流程总览](./02_TLS握手全流程总览.md) 一章，就能在面试或聊天时把 TLS 握手讲出个大概；其余章节是"追问深度"用的。

## 一句话版本（先记住这个）

**TLS 握手 = 客户端和服务器互相打招呼（Hello）→ 服务器亮出身份证明（证书）→ 双方共同凑出三个随机数 → 用这三个随机数算出同一把会话密钥 → 验证成功，开始用这把钥匙加密通信。**
