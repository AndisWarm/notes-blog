# 系统设计面试知识讲解（小林 coding 系统设计面试题）

面向编程小白的系统设计面试知识讲解，基于小林 coding「系统设计面试题」页面（[原文链接](https://www.xiaolincoding.com/interview/systemdesign.html)），把高频面试题逐个拆开讲透。

系统设计面试题考察的不是死记硬背，而是**面对一个具体业务场景，你能不能画出完整的架构链路、说出每一层的职责和取舍**。所以每个章节都遵循「一句话回答 → 展开讲 → 比喻 → 面试怎么答」的结构：先用一句话抓住主干，再逐层展开细节，用生活化比喻帮你建立直觉，最后给出面试汇报的话术主线。

## 推荐阅读顺序

1. 先读 [01_秒杀系统设计](01_秒杀系统设计.md)——它是「层层漏斗」思想的代表作，一条链路把 CDN、网关、Redis、MQ、数据库全串起来了，建立了对系统架构的整体感觉；
2. 再读 [03_短链系统设计](03_短链系统设计.md) 和 [04_点赞系统设计](04_点赞系统设计.md)——分别是「读多写少」和「高频读写」两个典型场景的样板，理解 Redis + MQ + MySQL 的黄金组合；
3. [02_RPC框架设计](02_RPC框架设计.md) 和 [05_分布式ID发号器设计](05_分布式ID发号器设计.md) 是「造轮子」类题目，考察对底层原理的理解，可以和分布式基础配合学习；
4. [06_订单超时取消方案](06_订单超时取消方案.md) 是方案对比题的代表，重点学**对比思维**（同一需求多种实现，各有优劣）;
5. 最后读 [07_QPS暴涨10倍应对](07_QPS暴涨10倍应对.md)，它把前面所有手段（限流、缓存、MQ、分库分表）在「10 倍流量」的场景下做了一次总复习。

## 学习方法建议

- 每章先看「一句话回答」，合上书自己复述一遍，能说出来就说明主干掌握了；
- 再用「面试怎么答」段落模拟面试官提问，练习用「总—分—总」结构回答；
- 系统设计没有唯一标准答案，重点在于**说出每一层为什么这么设计、有什么取舍**（比如 301 vs 302、Lua 脚本 vs 先查后减）。
