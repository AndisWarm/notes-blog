## 每章的阅读方法

每道题都按这个结构讲：

1. **一句话答案**：面试时先答这句拿分。
2. **大白话讲解**：用生活类比把原理讲透，方便理解而不是死记。
3. **面试官追问点**：原题里标出的"一深问就卡壳"的地方，重点看。

## 高频重点（时间不够只看这些）

- **TCP 三次握手/四次挥手**：过程 + 为什么是三次/四次 + 每次丢包会发生什么 + TIME_WAIT 怎么来的。
- **HTTP 和 HTTPS**：区别、TLS 握手四步、为什么能防中间人。
- **TCP 可靠传输和拥塞控制**：慢启动、拥塞避免、快重传、快恢复四个阶段。
- **网络排查场景题**：越来越常见，考对协议的整体理解。

> 提示：文中涉及 Linux 内核参数（如 `tcp_syn_retries`）属于加分项，面试时能说出来很加分，但记不住也不影响拿基础分。
