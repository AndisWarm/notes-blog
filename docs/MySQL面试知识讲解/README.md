## 推荐阅读顺序

1. 先过一遍 [01](01_SQL基础与数据类型.md) 和 [02](02_SQL实战题.md)，建立 SQL 手感
2. 再学 [04](04_索引基础.md)，索引是 MySQL 面试核心（联合索引、索引优化都在本章）
3. 然后 [05](05_事务.md) → [06](06_锁.md) → [07](07_日志.md)，这三章是深水区，建议连起来读
4. 最后 [03](03_存储引擎.md)、[08](08_性能调优.md)、[09](09_架构.md) 收尾
