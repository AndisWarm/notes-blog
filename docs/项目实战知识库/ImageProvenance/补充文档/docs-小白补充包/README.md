## 怎么用

```text
先读 00 总览（10 分钟）
  → 按需读 01–08（每篇 20–40 分钟，和原 docs 对应篇章对照着读）
  → 遇到陌生词随时翻 09 术语表
```

**核心用法**：先读本包的对应篇，再回去读原 docs 那篇——本包是"前情提要 + 大白话翻译"，原 docs 才是"正片"。

## 三个重要提醒

1. **本包不写代码**——代码层面的学习请用 `learning-小白补充包` + `learning/`。
2. **本包会简化**——为了讲明白，有些细节会省略或比喻化；做毕设/答辩时，一律以原 docs 的表述为准（那是口径）。
3. **本包的"为什么"是常识层解释**——比如"为什么作者自己发交易更可信"，这是为了帮你建立直觉；正式答辩口径看原 docs/07。
