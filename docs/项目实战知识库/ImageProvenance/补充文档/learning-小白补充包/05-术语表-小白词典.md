## E. 易混词速查（高频翻车点）

| 容易混的两个词 | 区别 |
|---|---|
| 原图 vs 签名分发版 | 原图没有 C2PA 声明；改原图 = "无记录"，改分发版 = "签名后被篡改" |
| 密码学哈希 vs 感知哈希 | SHA-256 差一点全变（防篡改）；pHash 像一点就接近（查相似） |
| 签名有效 vs 签名可信 | 有效 = 没被改且是持钥人签的；可信 = 还要根证书在信任列表里 |
| 连接钱包 vs 确认交易 | 连接只是亮身份；每次操作都会再弹窗逐笔确认 |
| 链上数据 vs 数据库镜像 | 链是唯一真相；SQLite 是监听器抄来的副本，可删可重建 |
| 登记 vs 授权 | 登记 = "这图是我的"；授权 = "我允许你用" |
| 部署 vs 启动 | 部署 = 把合约刻到链上（每次重启链后要做）；启动 = 拉起服务进程 |
| nonce 清零 vs 链清零 | Hardhat 重启链数据没了，但 MetaMask 还记着旧 nonce，必须手动清 |
