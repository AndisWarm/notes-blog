```text
00 热身（半天）
  → 01 把环境搭好、五个窗口跑起来（1 天，卡住就翻 06）
  → 02 + 03 建立直觉（各半天，可先跳读，遇到看不懂再回来）

```

> 原 `learning/README.md` 里 01–10 章是**正片**，本包是**前传 + 工具书**。
> 每份补充文档末尾都有"回到正片"指引，指出你现在的水平可以回去读哪一章。

## 三个重要提醒

1. **本包不教你怎么改代码**——改代码请回原 `learning/09、10`，那里的深度本包不重复。
2. **命令全是 PowerShell 版本**——原文档里的 `bash` 命令（如 `sha256sum`、`<(...)`）在
   Windows 上不能直接跑，本包 00 和 03 给了对应写法；`bash`（Git Bash）里能跑的
   会在文中明确标注。
3. **本包不保证版本号永远准确**——软件版本以 `manual/01` 的表和实际安装为准。
