## 读前唯一需要知道的一件事

这个系统解决一个很朴素的问题:**"我拍了一张照片,怎么证明这是我拍的、
后来有没有被人改过、我用它授权给别人是真是假?"**

它的答案是:给文件做"指纹"(哈希)、盖"防伪章"(数字签名)、把记录写进
"无法篡改的公开账本"(区块链),再提供一套"验证台"(网页)让任何人检查。
整套系统就是围绕这四个词展开的——第 00 篇会逐个讲清楚。

## 三套文档的关系(摘自项目 README)

- `manual/` 教你**用**;
- `manual-beginner/`(本目录)教你**看懂再用**;
- `learning/` 教你**懂到能改代码**(面向开发者,更深入);
- `docs/` 是开发过程材料(设计、答辩、日志)。

> 学习顺序建议:本目录 00 → 01 → 02 → 03 → 04 → 05 → 06 → 07;
> 想深入了解原理,再进 `learning/`;准备答辩再看 `docs/07、08`。
