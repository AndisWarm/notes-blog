**分层原则**（面试常问）：
> 失败定位成本递增，所以断言尽量下沉——"非作者授权被拒"在 L1 用一行 expect revert 测，不需要起五个服务；"授权记录 3 秒内出现在 API"只能在 L3 测（跨了链、监听器、SQLite 三个部件）。

## 9.2 L1 合约单测：攻击用例的思维方式

### 六组攻击用例对照表

| 威胁场景 | 防御机制 | 测试用例 |
|---------|---------|---------|
| 抢注他人作品 | 三哈希链上查重 revert | 重复注册三个哈希各一次 |
| 替他人发授权 | `authorOf == msg.sender` | 非作者 grantLicense revert "not author" |
| 篡改他人分账 | 同上 | 非作者 setRoyaltyRule revert |
| 操作不存在的作品 | `workExists` 校验 | 幽灵 workId 各方法 revert |
| 撤销/过期后仍有效 | isLicensed 逻辑 | 时间快进用 evm_increaseTime |
| 越权改状态 | `author == msg.sender` | 非作者 setStatus revert |

**方法论**（面试话术）：
> "先写威胁模型，再让每条威胁对应至少一个'必须失败'的用例。权限系统的测试重点不是'能用'，是'**该失败的必须失败**'。每个正向用例旁边都站着它的反面。"

### 代码示例

```javascript
// contracts/test/LicenseV2.test.js
it("reverts when non-author tries to grant license", async () => {
    await expect(
        license.connect(attacker).grantLicense(workId, attacker.address, "test", future)
    ).to.be.revertedWith("not author");
});
```

### similarity/phash_probe_test.go

**把实验发现固化成测试**的范例：

> 噪声图/渐变图是 pHash 病态输入——前者低频能量弱、后者 DCT 系数贴近中位数，微小修改就产生 20+ 距离；自然图像则表现正常。

这个结论不是写在文档里，是写成会跑的断言（文档会过时，测试不会说谎）。

## 9.7 动手实验：补一个断言

`RoyaltyV2.test.js` 现有用例没有断言 **RoyaltyRuleSet 事件的参数**。补上：

```javascript
it("emits RoyaltyRuleSet with full params", async () => {
    await expect(royalty.connect(author).setRoyaltyRule(workId, platform.address, 8500, 1500))
        .to.emit(royalty, "RoyaltyRuleSet")
        .withArgs(workId, author.address, platform.address, 8500, 1500);
});
```

**思考**：这个断言在防御什么回归？
> 事件字段顺序/类型被改 → 链下解析悄悄坏掉。事件是链上链下的**接口契约**，契约要有契约测试。

## 9.8 面试高频追问

**Q: "非作者不能授权"在 L1 和 L3 各测了一次——重复吗？**
> 不重复。L1 测"合约逻辑正确"，L3 测"真实链+真实 ABI 上仍正确"。L1 用 mock，L3 用真实环境，防御不同层面的回归。

**Q: 为什么 E2E 每轮要生成随机图？**
> 复用固定图会撞防重复注册——第二次跑就 409 了。随机图保证可重跑。

**Q: sleep 3.5s 的依据是什么？改成 1s 会怎样？**
> 2s 轮询间隔 + 处理余量。改 1s 可能事件还没到，测试不稳定。更好的写法是轮询直到条件满足，但 sleep 简单直接。

**Q: "测试自身可重跑"在本项目栽过什么坑？**
> validUntil 用 Date.now() 基准，evm_increaseTime 后链时间领先 2 小时，第二遍跑就误报 invalid expiry。根因：测试依赖墙钟而非链上时间。修法：统一用 latest block timestamp。

**Q: 独立环境回归发现的那个缺陷，为什么 L1–L3 全绿却漏过了它？**
> c2patool 0.27 的 digitalSourceType 强制字段是规范演进，本机 0.26 没问题，云端 0.27 才爆。L1–L3 都在本机同版本下跑，自然漏过。只有换环境才能发现环境耦合。
