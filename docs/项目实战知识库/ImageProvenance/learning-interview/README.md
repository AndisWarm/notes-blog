## 快速使用指南

### 面试前 1 小时
直接读 [10-面试实战问答](10-面试实战问答.md) 和 [11-项目亮点与难点](11-项目亮点与难点.md)

### 面试前 1 天
通读 [03-系统架构全景](03-系统架构全景.md) + [04-智能合约详解](04-智能合约详解.md) + [05-后端管道详解](05-后端管道详解.md)

### 面试前 1 周
按 01→02→03→04→05→06→07→08→09 顺序完整学习

### 被问到不懂的概念时
回到 [02-核心概念扫盲](02-核心概念扫盲.md) 找到对应词条

## 一句话记住这个项目

> 这是一个让摄影师/画师能证明自己"在某个时间创作了某张图"的系统：用区块链存指纹防止抵赖，用 C2PA 标准把证明嵌入图片本身，用智能合约管理授权和分成，全部过程创作者自己控制，平台无法伪造。
