## 里程碑

### M2 C2PA 信任链（约 0.5 周，可与 M1 并行）

- [x] openssl 脚本：Root CA + ES256 签名证书（含 C2PA EKU），入库 `tools/ca/`（make-ca.sh + ca.cnf）
- [x] c2patool 签名切换到自建证书（manifest 的 alg/private_key/sign_cert 字段）；验证用 `trust --trust_anchors rootCA.pem`

- **验收**：`c2patool verify` 显示签名可信

### M3 后端改造（约 1–1.5 周）

- [x] 移除后端签名私钥与代签路径；新增 `POST /api/works/prepare`（返回三哈希 + CID + calldata + txRequest）
- [x] 哈希三元组计算（原图 / 签名图 / manifest），c2patool 用自建证书签名并以 trust anchor 验证（c2paStatus=trusted）
- [x] FilterLogs 事件监听 + `lastProcessedBlock` 断点续扫 + SQLite 索引（modernc.org/sqlite，works/licenses/chain_cursor 三表）
- [x] 作品状态机（UPLOADED→SIGNED→PINNED→PENDING_ANCHOR→ANCHORED）；断点续扫即对账（离线期间事件重启后自动补齐，已实测）
- [x] `verify-file` 升级为三元组分层验证（original/signed/manifest-only/none 四态 + 链上 getWorkByHash 兜底），新增 `GET /api/chain/info`
- **验收**：手动 kill 后端再重启，索引自动补齐重启期间链上新事件

### M4 前端重构（约 1–1.5 周）
