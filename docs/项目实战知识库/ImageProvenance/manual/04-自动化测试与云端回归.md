# 04 自动化测试与云端回归

两种跑法:**本机脚本**(需五服务在跑,几分钟出结果)与**云端自动化回归**
(交给 Claude Cowork 云端沙箱,不占本机、不依赖本机服务状态)。

## 一、本机自动化测试

| 命令 | 用例 | 前置 | 说明 |
|---|---|---|---|
| `cd contracts && npm test` | 20(含 6 组攻击用例) | 无需服务 | 合约单测,内置 Hardhat 网络;`npx hardhat coverage` 出覆盖率(98.5%) |
| `cd backend && go test ./...` | repository / c2pa / similarity | 无需服务 | 后端单测 |
| `node scripts\dev\e2e-demo.mjs` | 15 | 五服务已启动 | 全链路验收:prepare→上链→镜像→四态→PDF,双账户正反用例 |
| `node scripts\dev\test-license-flow.mjs` | 22 | 五服务已启动 | 状态流转 + 授权/撤销/过期/越权 + 分账专项 |
| `node scripts\dev\test-license-flow-extended.mjs` | 31 | 五服务已启动 | 边界扩展:负例参数、幽灵 ID、双重撤销、hasRule、**状态镜像**、faucet 回归 |
| `node scripts\dev\collect-performance.mjs 10` | — | 五服务已启动 | 10 轮性能与 Gas 采集 → `reports/test-results/` |

E2E 类脚本用 Hardhat 公开测试账户直接签名,**不需要 MetaMask 参与**;
每轮生成随机像素 PNG,哈希唯一,可反复运行。

> **长活节点重跑注意**:`test-license-flow*.mjs` 会调用 `evm_increaseTime` 把链时间快进
> 2 小时且**不可回退**。extended 脚本以链上区块时间为基准,不受影响、可连续重跑;
> 主脚本 `test-license-flow.mjs` 用墙钟(`Date.now()`)计算有效期,在**同一条不重启的节点**
> 上第二次运行会误报 `invalid expiry`(合约行为正确)——重启 Hardhat 再跑即可,或把该行
> 换成 `(await provider.getBlock('latest')).timestamp`。

## 二、云端自动化回归(Claude Cowork)

2026-07-26 的两轮全量回归(**76/76 通过**)即以此方式完成,适合:本机服务没起、
不想被占用机器、或想要"从源码从零复刻环境"级别的独立验证。

**它做了什么**:云端沙箱内从项目源码搭出等价环境——用 go-ethereum v1.16.7 内核构建
与 Hardhat 等价的开发链(chainId 31337、同一组测试账户、支持
`evm_increaseTime`/`hardhat_setBalance`,合约部署地址与本机完全一致)、离线构建 Go 后端、
从 crates.io 安装 c2patool——然后把 `e2e-demo.mjs` / `test-license-flow.mjs` 的全部用例
以等价实现跑一遍,外加边界用例、断点续扫、编码回归等补充场景。
可信度锚点:`registerWork` gas 云端 412,516 vs 本机 412,528;四合约地址逐一相同。

**怎么发起**:Claude 桌面版新建 Cowork 任务 → 连接本项目文件夹 → 直接说明要测的范围,例如:

> 帮我云端自动化回归:作品签名上链后的所有状态、授权管理中的签发授权方 / 分账 / 授权记录。
> 发现小问题直接修并回写。

无需本机启动任何服务;进行中可以关笔记本,云端会话继续执行。

**产出**:
- 测试报告写入 `reports/test-results/`(用例-预期-实测明细、环境差异表、问题分析);
- 确认的缺陷修复直接回写项目文件,并在 `docs/04-开发日志.md` 追加记录;
- 新增的可复跑脚本(如 `test-license-flow-extended.mjs`)同步落库。

**已知局限(云端跑不了、需本机补验的三件事)**:
1. `web` 的 `npm run build` / vite 构建(沙箱无 npm 源)——前端改动云端只做语法级校验;
2. RFC3161 时间戳实测(沙箱无公网 TSA)与 IPFS 模式(以本地内容寻址存储等价替代);
3. MetaMask 真实弹窗交互——属人工验收环节,按第 03 篇走一遍即可。
