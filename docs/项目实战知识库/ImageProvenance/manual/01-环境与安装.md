# 01 环境与安装

## 依赖环境

| 依赖 | 版本 | 用途 | 获取方式 |
|---|---|---|---|
| Node.js | ≥ 18(项目实测 22) | Hardhat 链、前端 Vite、测试脚本 | nodejs.org |
| Go | ≥ 1.25 | 后端 | go.dev |
| MetaMask | 浏览器插件 | 创作者钱包签名(系统不代签) | metamask.io |
| c2patool | 0.26+(0.27 已验证兼容) | C2PA 签名与 trust 验证 | 已内置 `tools/bin/c2patool.exe` |
| Kubo(IPFS) | 0.40.x | 分布式存储(可选,不启用时自动落本地内容寻址存储) | 已内置 `tools/bin/ipfs.exe` |
| OpenSSL | 任意近代版本 | 首次生成 demo CA(Git Bash 自带) | — |
| PowerShell | Windows 自带 | 启动脚本 | — |

> 内置的两个 exe 是 Windows x64 版本;其他平台请自行下载对应二进制并通过环境变量
> `C2PATOOL_PATH` / IPFS 安装路径指向它们。
>
> **c2patool 版本注意**:0.27+(C2PA 2.1 规范)要求 `c2pa.created` 动作携带
> `digitalSourceType` 字段,本项目 manifest 已内置该字段,0.26 与 0.27 均验证通过;
> 若自行修改 `backend/internal/c2pa/manifest.go` 的断言结构,请保留它,否则新版工具会把
> 所有签名判为 Invalid。

## 首次安装(只做一次)

```powershell
# 1. 安装前端与合约依赖
cd contracts; npm install
cd ..\web;    npm install

# 2. 生成 demo CA(Git Bash 中执行;Root CA + ES256 叶子证书 + 信任链)
bash tools/ca/make-ca.sh
#    产物:tools/ca/{rootCA.pem, sign.key, sign.crt, sign-chain.pem}
#    重要:Git Bash 会把 openssl 的 -subj 参数当路径改写,脚本内已用 MSYS_NO_PATHCONV=1 处理

# 3. (可选)IPFS 初始化——不做这步系统会用本地内容寻址存储,功能不受影响
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\dev\start-ipfs.ps1
```

后端依赖(Go modules)在首次 `start-backend.ps1` 时自动下载到项目内缓存
(`.cache/go-mod`),无需手动操作。

## 可选配置(环境变量,启动后端前设置)

| 变量 | 作用 | 示例 |
|---|---|---|
| `TSA_URL` | RFC3161 可信时间戳(与区块时间构成双锚定);不配或网络失败时优雅跳过 | `https://freetsa.org/tsr` |
| `PDF_UNICODE_FONT` | 证据 PDF 中文字体;`start-backend.ps1` 会自动探测 simhei.ttf | `C:\Windows\Fonts\simhei.ttf` |
| `STORAGE_MODE` | `ipfs`(默认)或 `local`(不起 Kubo 时自动回退) | `local` |
| `APP_PORT` / `CHAIN_RPC_URL` | 后端端口 / 链 RPC 地址 | `8080` / `http://127.0.0.1:8545` |

完整变量清单见 `scripts/dev/start-backend.ps1` 与 `backend/internal/config/config.go`。

## 已知的三个环境坑(都有现成解法)

1. **Windows curl 上传中文标题会乱码**:curl 按 GBK 发送表单,后端已做 UTF-8 校验并直接
   400 拒绝——用网页上传或任何 UTF-8 客户端即可。
2. **Git Bash 路径改写**:`openssl -subj /C=CN/...`、`ipfs config /ip4/...` 这类参数会被
   Git Bash 当路径重写,相关脚本已内置 `MSYS_NO_PATHCONV=1`;自己敲命令时记得带上。
3. **MetaMask 本地链 nonce 错乱**:重启 Hardhat 后链归零,而 MetaMask 记着旧 nonce,
   发交易会一直 pending——MetaMask 设置 → 高级 → 清除活动与 nonce 数据,选中该账户即可。
