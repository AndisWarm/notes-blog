# 01 跑起来:首次全流程体验

**学习目标**:不求懂原理,求把系统完整跑一遍,并在每一步**留下观察记录**——后面九章
所有概念都会挂在你今天看到的现象上。

**前置**:Windows + Node 18+ + Go 1.25 + MetaMask 已装。安装步骤照抄
[`../manual/01-环境与安装.md`](../manual/01-环境与安装.md),启动照抄
[`../manual/02-启动与健康检查.md`](../manual/02-启动与健康检查.md)。

## 1.1 启动时观察什么(不要只是等它跑起来)

按 manual/02 的五窗口顺序启动,每个窗口回答一个问题并记下来:

| 窗口 | 观察任务 |
|---|---|
| Hardhat | 找到打印出的 20 个账户和私钥——问自己:为什么开发链敢把私钥印在屏幕上? |
| deploy | 记下四个合约地址;打开 `contracts/deployments/localhost.json` 对照——这个文件后面谁在读? |
| 后端 | 找到日志行 `signer mode: creator-wallet` 和 `chain listener started (registry=0x... license=0x...)`——两个地址眼熟吗? |
| 前端 | Vite 起来后先**别开浏览器**,用 `curl http://127.0.0.1:8080/api/chain/info` 看看前端将要拿到什么 |
| 健康检查 | 逐字段读懂 `/api/health` 输出(字段含义表在 manual/02) |

## 1.2 完整走一遍业务(跟 manual/03,但带观察任务)

照 [`../manual/03-演示-多账户登记授权与分账.md`](../manual/03-演示-多账户登记授权与分账.md)
用甲/乙两个账户走完六个场景。每个场景多做一件事:

1. **登记上链**:点"① 生成声明与签名"之后、点"②"之前,**停下来**——
   打开浏览器开发者工具 Network 面板,找到 `/api/works/prepare` 的响应,把 `txRequest`
   的内容抄下来(to 是谁?data 前 8 个十六进制字符是什么?)。这是第 04、05 章的核心线索。
2. **授权签发**:MetaMask 弹窗时点开"数据"标签,看它要签的是什么;确认后盯着授权记录表,
   数一数几秒后出现(这个延迟从哪来?第 06 章揭晓)。
3. **越权攻击**:切乙账户操作,把红色错误提示原文抄下来——"合约拒绝"四个字是谁翻译的?
   (提示:`web/src/views/LicenseView.vue` 搜 `revertReason`)
4. **分账**:设置 85/15 后看回显;再想:页面刷新后回显还在——数据存在哪了?
   (答案会颠覆直觉:不在后端数据库,第 07 章讲)
5. **状态标记**:标记争议后去验证页查同一作品,看红色警示。
6. **四态验证**:四种文件各传一次,把四个结论截图。签名分发版从
   `backend/data/objects/<CID>/`(local 模式)或 IPFS 网关取。

## 1.4 破坏性实验(建立"什么会坏、怎么恢复"的手感)

1. 关掉后端窗口 → 前端还能验证吗?还能上链吗?(试试)→ 重启后端,观察它补了什么日志;
2. 关掉 Hardhat 再重启 → 一切归零(为什么?链数据在内存)→ 体验 manual/02 里
   "重启 Hardhat 后要重新部署 + 删 index.db + 清 MetaMask nonce"的完整恢复手顺——
   这个手顺你后面会用几十次,现在就练熟。

## 自测(答不上就重跑对应小节)

1. 五个服务的启动顺序为什么不能乱?(两条依赖关系)
2. `txRequest` 里有哪三个字段?哪个字段决定了"这笔交易在调用哪个合约"?
3. 授权记录从"上链成功"到"页面表格出现"隔了几秒?这中间系统在做什么(猜)?
4. 把一张已登记的图用画图工具改一个像素再验证,结果是四态中的哪一态?为什么不是"签名后被篡改"?
   (提示:你改的是**原图**还是**签名分发版**?)
5. 重启 Hardhat 之后,不删 `backend/data/index.db` 会发生什么现象?

> 4 的答案值得先想清楚:改**原图**→哈希全变、文件里也没有 C2PA 声明→"无记录";
> 只有改**签名分发版**(内嵌声明幸存)才会触发"签名后被篡改"。分不清这两个,第 05 章会卡住。
