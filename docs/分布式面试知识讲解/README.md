# 分布式面试知识讲解

面向编程小白的分布式面试八股文详解，按主题分章节。延续 MySQL、Redis 笔记的写作风格：每个问题都有「一句话回答 → 展开讲 → 比喻 → 面试怎么答」，用大白话把底层原理讲透。

## 目录

| 章节 | 主题 | 覆盖问题 |
|------|------|----------|
| [01_分布式理论](01_分布式理论.md) | 分布式系统、分布式 vs 微服务、CAP、BASE | 什么是分布式系统、分布式和微服务有什么区别、介绍一下 CAP 理论、怎么理解 BASE 理论 |
| [02_分布式锁](02_分布式锁.md) | Redis 实现、Zookeeper 实现、选型 | 用 Redis 怎么实现分布式锁、还有没有其他方法实现（Zookeeper）、怎么选型 |
| [03_分布式ID](03_分布式ID.md) | 使用场景、四种方案对比 | 什么情况需要用分布式 ID、分布式 ID 有什么方案（UUID / 号段 / Redis / 雪花） |
| [04_分布式事务](04_分布式事务.md) | 使用场景、六大方案、Seata | 什么情况下需要使用分布式事务、解决方案有哪些（2PC/3PC/TCC/Saga/MQ/本地消息表）、阿里的 Seata 框架了解过吗 |

## 推荐阅读顺序

1. 先过 [01_分布式理论](01_分布式理论.md)，搞清楚「为什么要分布式」和 CAP/BASE 这两个最常问的理论基石
2. 再学 [03_分布式ID](03_分布式ID.md) 和 [02_分布式锁](02_分布式锁.md)，这两个是分布式最基础的落地组件，面试出现频率极高
3. 最后啃 [04_分布式事务](04_分布式事务.md)，内容最重，六大方案要能讲清「各自解决什么问题、代价是什么」
