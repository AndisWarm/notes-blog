08. 前端架构：Vue3 + Pinia + Axios + Element Plus¶

一、本章要解决的问题¶

前端怎么组织代码？页面怎么跳转？数据怎么流转？权限怎么控制？

二、技术栈选型¶

技术 作用 为什么选它
Vue 3 前端框架 组合式 API、响应式、生态成熟
Vite 构建工具 启动快（秒级），HMR 热更新
Vue Router 路由 官方路由，支持路由守卫
Pinia 状态管理 比 Vuex 更简洁，TypeScript 友好
Axios HTTP 客户端 拦截器机制方便统一处理 token 和错误
Element Plus UI 组件库 中后台标配，组件全
ECharts / vue-echarts 图表 功能强大，支持地图/趋势/分布图

2. 全局路由守卫¶

// router/index.js
import { useUserStore } from '@/pinia/modules/user'

router.beforeEach(async (to, from, next) => {
    const userStore = useUserStore()

    // 1. 如果页面不需要登录，直接放行
    if (!to.meta.requiresAuth) {
        next()
        return
    }

    // 2. 检查是否有 token
    if (!userStore.token) {
        next('/login')
        return
    }

    // 3. 如果有 token 但没有用户信息，先拉取
    if (!userStore.userInfo.username) {
        try {
            await userStore.getCurrentUser()
        } catch (err) {
            // token 失效，跳转登录页
            userStore.logout()
            next('/login')
            return
        }
    }

    // 4. 检查角色权限
    if (to.meta.roles && !to.meta.roles.includes(userStore.userInfo.roleCode)) {
        ElMessage.error('当前账号无权访问此页面')
        next('/security/overview')  // 跳到总览页
        return
    }

    next()
})

执行时机：每次路由跳转前都会执行。

六、Axios 封装和拦截器¶

文件：web/src/api/request.js

1. 创建 Axios 实例¶

import axios from 'axios'

const request = axios.create({
    baseURL: '/api/v1',  // 所有请求都加 /api/v1 前缀
    timeout: 10000,
})

2. 请求拦截器¶

request.interceptors.request.use(
    config => {
        // 自动带 token
        const token = localStorage.getItem('token')
        if (token) {
            config.headers.Authorization = `Bearer ${token}`
        }
        return config
    },
    error => Promise.reject(error)
)

3. 响应拦截器¶

request.interceptors.response.use(
    response => {
        // 后端统一返回格式：{ code: 0, data: {...}, message: "success" }
        if (response.data.code !== 0) {
            ElMessage.error(response.data.message || '请求失败')
            return Promise.reject(new Error(response.data.message))
        }
        return response.data  // 只返回 data 部分
    },
    error => {
        if (error.response?.status === 401) {
            // 401：token 失效
            ElMessage.error('登录状态已失效，请重新登录')
            localStorage.removeItem('token')
            window.location.href = '/login'
        } else if (error.response?.status === 403) {
            // 403：无权限
            ElMessage.error('当前账号无权执行此操作')
        } else if (error.response?.status === 500) {
            // 500：服务器错误
            ElMessage.error('服务器错误，请稍后重试')
        }
        return Promise.reject(error)
    }
)

export default request

七、Pinia 状态管理¶

文件：web/src/pinia/modules/user.js

import { defineStore } from 'pinia'
import { login, getCurrentUser, logout } from '@/api/user'

export const useUserStore = defineStore('user', {
    state: () => ({
        token: localStorage.getItem('token') || '',
        userInfo: {},
    }),

    actions: {
        async login(loginForm) {
            const res = await login(loginForm)
            this.token = res.token
            this.userInfo = res.userInfo
            localStorage.setItem('token', res.token)
        },

        async getCurrentUser() {
            const res = await getCurrentUser()
            this.userInfo = res.userInfo
        },

        async logout() {
            await logout()
            this.token = ''
            this.userInfo = {}
            localStorage.removeItem('token')
        },
    },
})

在组件中使用：

<script setup>

import { getTaskDetail } from '@/api/securityTask'

const route = useRoute()
const taskId = route.params.id

const loading = ref(true)
const error = ref('')
const detail = ref({})

const fetchDetail = async () => {
    try {
        loading.value = true
        const res = await getTaskDetail(taskId)
        detail.value = res
    } catch (err) {
        error.value = err.message || '获取任务详情失败'
    } finally {
        loading.value = false
    }
}

onMounted(() => {
    fetchDetail()
})
</script>

关键点： - loading / error / detail 三态管理 - v-if="loading" → 骨架屏 - v-else-if="error" → 错误提示 - v-else → 正常内容

十、本章 Q&A¶

Q：为什么用 Pinia 不用 Vuex？ A： - Pinia 是 Vue 3 官方推荐的状态管理库 - 比 Vuex 更简洁（不用写 mutations） - TypeScript 支持更好 - 支持 Composition API

Q：为什么 token 存 localStorage 不存 cookie？ A： - localStorage 操作简单，localStorage.setItem('token', xxx) - cookie 有 CSRF 风险，需要额外配置 SameSite - localStorage 有 XSS 风险，但可以通过 CSP 和输入过滤缓解

Q：前端怎么处理 401 和 403？ A： - 401：token 失效 → 清除 token，跳转登录页 - 403：无权限 → 提示"当前账号无权访问"，跳转总览页

Q：为什么要在响应拦截器里统一处理错误？ A：避免每个页面都写一遍错误处理逻辑。拦截器统一处理 401/403/500，页面里只用处理业务错误。

Q：前端路由守卫和 Axios 拦截器都会处理 401，会不会重复？ A：不会。 - 路由守卫处理页面级 401：跳转页面前检查 token - Axios 拦截器处理接口级 401：请求返回 401 时清除 token

两者配合，保证用户体验和安全。
